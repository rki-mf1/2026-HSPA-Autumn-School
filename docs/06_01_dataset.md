# Public mpox ONT dataset for the tutorials

For the bioinformatics practicals, we use a small teaching subset of publicly available **Oxford Nanopore Technologies (ONT) mpox amplicon sequencing data** from:

> Chen NFG, Chaguza C, Gagne L, et al. (2023).  
> **Development of an amplicon-based sequencing approach in response to the global emergence of mpox.**  
> *PLOS Biology* 21(6): e3002151.  
> DOI: [10.1371/journal.pbio.3002151](https://doi.org/10.1371/journal.pbio.3002151)

The study developed and validated the **Yale hMPXV amplicon scheme**, consisting of approximately 2-kb tiled amplicons across the MPXV genome.

For the teaching dataset, we focus on the samples generated by **Johns Hopkins Medical Institutions (JHMI)** because these samples were:

- clinical lesion swabs;
- amplified with the Yale mpox amplicon approach;
- prepared using NEBNext ARTIC reagents;
- sequenced using an Oxford Nanopore Technologies **GridION**;
- analyzed using an ARTIC bioinformatics workflow.

The publication reports **eight JHMI ONT samples**. Instead of downloading all of them, we select four samples that provide a useful range of sequencing outcomes for teaching.

---

## 🎯 Learning objectives

By the end of this tutorial, you will be able to:

- retrieve sample metadata from a published study;
- identify public SRA run accessions;
- download raw sequencing reads with the NCBI SRA Toolkit;
- organize ONT FASTQ data into barcode directories;
- create a sample sheet for downstream analysis;
- verify that the downloaded files are ready for later tutorials.

The same directory structure can subsequently be used for:

1. read quality control;
2. `artic-mpxv-nf`;
3. consensus genome quality assessment;
4. Nextclade clade/lineage assignment;
5. comparative and phylogenetic analyses.

# 1. Dataset background

The Yale hMPXV primer scheme was designed against the pre-outbreak Clade IIb A.1 genome **MT903345**.

The scheme contains **163 primer pairs**, producing amplicons approximately **1,597–2,497 bp** long, with a mean amplicon length of approximately **1,977 bp**.

The study showed that both viral concentration and sequencing depth influence genome recovery. The authors recommended prioritizing samples with **Ct <31** and generating approximately **1 million reads per sample** when resources allow.

This makes the dataset useful for teaching because students can compare samples with different levels of genome recovery rather than analyzing only perfect examples.

---

# 2. Teaching subset

We will select four JHMI ONT samples from the study metadata.

The selection is intentionally designed to include different sequencing outcomes:

| Teaching sample | Selection principle | Why it is useful |
| --- | --- | --- |
| `barcode01` | High genome coverage, Ct <31 | Good-quality example |
| `barcode02` | Representative intermediate Ct sample | Typical sequencing result |
| `barcode03` | Higher Ct but still useful genome recovery | Demonstrates effect of lower template concentration |
| `barcode04` | Lower-coverage JHMI sample | Useful QC/troubleshooting example |

The exact specimen IDs and SRA run accession numbers are read directly from the study's **S3 Table**, which contains the institute, specimen code, Ct value, sequencing platform, genome coverage and accession numbers.

> **Why obtain the accessions from the supplementary table?**
>
> The study contains data from many laboratories and multiple sequencing platforms. Reading the sample information directly from the publication metadata reduces the risk of accidentally downloading an Illumina or non-JHMI sample with a similar name.

# 6. Extract the JHMI ONT samples and choose the teaching subset

The following Python code reads the official S3 metadata, identifies **JHMI + ONT** records containing public SRA run accessions, and chooses four samples representing different sequencing outcomes.

Create the helper script:

```bash
cat > metadata/select_teaching_samples.py <<'PY'
import re
import sys
from pathlib import Path

import pandas as pd


INPUT = Path("metadata/chen_2023_s3.xlsx")
ALL_OUT = Path("metadata/jhmi_ont_samples.tsv")
SELECTED_OUT = Path("metadata/selected_samples.tsv")
SAMPLESHEET_OUT = Path("metadata/sample_sheet.csv")


def clean_name(x):
    return re.sub(r"[^a-z0-9]+", "_", str(x).strip().lower()).strip("_")


def find_column(columns, required_terms):
    for col in columns:
        lc = clean_name(col)
        if all(term in lc for term in required_terms):
            return col
    return None


def to_number(series):
    return pd.to_numeric(
        series.astype(str)
              .str.replace("%", "", regex=False)
              .str.replace(",", ".", regex=False)
              .str.extract(r"([-+]?[0-9]*\.?[0-9]+)", expand=False),
        errors="coerce",
    )


# Read all worksheets because supplementary-file layouts can change.
sheets = pd.read_excel(INPUT, sheet_name=None)

frames = []
for sheet_name, df in sheets.items():
    if df.empty:
        continue

    df = df.dropna(how="all").copy()
    df["source_sheet"] = sheet_name
    frames.append(df)

if not frames:
    sys.exit("No data rows were found in the supplementary spreadsheet.")

# Keep a union of all columns.
data = pd.concat(frames, ignore_index=True, sort=False)

# Search every cell in each row. This makes the extraction robust to small
# changes in the exact supplementary-table column names.
row_text = data.fillna("").astype(str).agg(" | ".join, axis=1)

jhmi = row_text.str.contains(
    r"JHMI|Johns Hopkins Medical",
    case=False,
    regex=True,
)

ont = row_text.str.contains(
    r"Oxford Nanopore|GridION|Nanopore|\bONT\b",
    case=False,
    regex=True,
)

data = data.loc[jhmi & ont].copy()

if data.empty:
    sys.exit("No JHMI ONT rows were detected. Inspect the S3 spreadsheet manually.")

# Extract SRA RUN accessions only: SRR..., ERR..., or DRR...
data["sra_runs"] = (
    data.fillna("")
        .astype(str)
        .agg(" ".join, axis=1)
        .apply(
            lambda x: ",".join(
                dict.fromkeys(re.findall(r"\b(?:SRR|ERR|DRR)\d+\b", x))
            )
        )
)

data = data[data["sra_runs"].str.len() > 0].copy()

if data.empty:
    sys.exit(
        "JHMI ONT rows were found, but no SRR/ERR/DRR run accessions were "
        "detected. Inspect S3 Table to determine which archive accessions "
        "are available for these samples."
    )

# Find useful metadata columns.
ct_col = (
    find_column(data.columns, ["ct"])
    or find_column(data.columns, ["cycle", "threshold"])
)

coverage_col = (
    find_column(data.columns, ["genome", "coverage"])
    or find_column(data.columns, ["coverage"])
)

specimen_col = (
    find_column(data.columns, ["specimen", "code"])
    or find_column(data.columns, ["sample", "code"])
    or find_column(data.columns, ["specimen"])
    or find_column(data.columns, ["sample"])
)

if ct_col is None:
    data["Ct"] = float("nan")
else:
    data["Ct"] = to_number(data[ct_col])

if coverage_col is None:
    data["genome_coverage"] = float("nan")
else:
    data["genome_coverage"] = to_number(data[coverage_col])

if specimen_col is None:
    data["specimen"] = ["JHMI_sample_%02d" % (i + 1) for i in range(len(data))]
else:
    data["specimen"] = data[specimen_col].astype(str).str.strip()

summary = data[
    ["specimen", "Ct", "genome_coverage", "sra_runs"]
].drop_duplicates().reset_index(drop=True)

summary.to_csv(ALL_OUT, sep="\t", index=False)

# ----------------------------------------------------------------------
# Teaching-set selection
# ----------------------------------------------------------------------
# We aim for:
#   1. a high-coverage Ct<31 sample;
#   2. a representative intermediate-Ct sample;
#   3. a higher-Ct usable sample;
#   4. a lower-coverage/challenging sample.
#
# If metadata are incomplete, unused samples are used to fill the set.
# ----------------------------------------------------------------------

chosen = []


def add_row(index):
    if index is None:
        return
    if index not in chosen:
        chosen.append(index)


usable = summary[summary["Ct"].lt(31)].copy()

# 1. Highest genome coverage among Ct <31.
if not usable.empty:
    if usable["genome_coverage"].notna().any():
        add_row(usable["genome_coverage"].idxmax())
    else:
        add_row(usable.index[0])

# 2. Ct closest to the median among Ct <31.
remaining = usable.loc[~usable.index.isin(chosen)]
if not remaining.empty and remaining["Ct"].notna().any():
    median_ct = remaining["Ct"].median()
    add_row((remaining["Ct"] - median_ct).abs().idxmin())

# 3. Ct closest to 30 among remaining Ct <31 samples.
remaining = usable.loc[~usable.index.isin(chosen)]
if not remaining.empty and remaining["Ct"].notna().any():
    add_row((remaining["Ct"] - 30).abs().idxmin())

# 4. Lowest genome coverage among the remaining JHMI ONT samples.
remaining = summary.loc[~summary.index.isin(chosen)]
if not remaining.empty:
    if remaining["genome_coverage"].notna().any():
        add_row(remaining["genome_coverage"].idxmin())
    else:
        add_row(remaining.index[-1])

# Fill to four samples if some criteria selected fewer unique rows.
for idx in summary.index:
    if len(chosen) >= 4:
        break
    add_row(idx)

selected = summary.loc[chosen[:4]].copy().reset_index(drop=True)

if selected.empty:
    sys.exit("No teaching samples could be selected.")

selected.insert(
    0,
    "barcode",
    [f"barcode{i:02d}" for i in range(1, len(selected) + 1)],
)

selected.to_csv(SELECTED_OUT, sep="\t", index=False)

sample_sheet = selected[["barcode", "specimen"]].rename(
    columns={"specimen": "alias"}
)
sample_sheet.to_csv(SAMPLESHEET_OUT, index=False)

print("\nAll JHMI ONT samples with SRA run accessions:")
print(summary.to_string(index=False))

print("\nSelected teaching samples:")
print(selected.to_string(index=False))

print(f"\nWritten: {ALL_OUT}")
print(f"Written: {SELECTED_OUT}")
print(f"Written: {SAMPLESHEET_OUT}")
PY
```

# 7. Download the selected SRA runs

NCBI's **SRA Toolkit** provides two useful commands:

- `prefetch` downloads an SRA run into the local SRA cache;
- `fasterq-dump` converts the downloaded SRA data into FASTQ.

Create a temporary directory:

```bash
mkdir -p sra_download
```

Download all run accessions listed in the teaching manifest:

```bash
tail -n +2 metadata/selected_samples.tsv \
    | cut -f5 \
    | tr ',' '\n' \
    | sort -u \
    > metadata/sra_runs.txt
```

Check the list:

```bash
cat metadata/sra_runs.txt
```

Download the runs:

```bash
while read -r RUN
do
    echo "Downloading $RUN"
    prefetch "$RUN" --max-size u
done < metadata/sra_runs.txt
```

> **Note**
>
> `--max-size u` removes the default maximum-download-size restriction. Public sequencing runs can be larger than the default limit.

---

# 8. Convert the SRA files to FASTQ

Convert each run to FASTQ:

```bash
while read -r RUN
do
    echo "Converting $RUN to FASTQ"

    fasterq-dump \
        --threads 8 \
        --outdir sra_download \
        "$RUN"
done < metadata/sra_runs.txt
```

Inspect the resulting files:

```bash
ls -lh sra_download/
```

Because these are ONT reads, the data are expected to be **single-end**, so each run should normally produce one FASTQ file.

Compress the FASTQ files:

```bash
gzip sra_download/*.fastq
```

# 9. Organize the reads into barcode directories

`artic-mpxv-nf` accepts a directory containing one level of barcode subdirectories:

```text
fastq_pass/
├── barcode01/
├── barcode02/
├── barcode03/
└── barcode04/
```

We will therefore map each public specimen to a workshop barcode.

Create the barcode directories and copy the corresponding FASTQ files:

```bash
python - <<'PY'
import csv
import shutil
from pathlib import Path

metadata = Path("metadata/selected_samples.tsv")
source = Path("sra_download")
target = Path("fastq_pass")

target.mkdir(parents=True, exist_ok=True)

with metadata.open() as handle:
    reader = csv.DictReader(handle, delimiter="\t")

    for row in reader:
        barcode = row["barcode"]
        outdir = target / barcode
        outdir.mkdir(parents=True, exist_ok=True)

        runs = [x.strip() for x in row["sra_runs"].split(",") if x.strip()]

        for run in runs:
            candidates = [
                source / f"{run}.fastq.gz",
                source / f"{run}_1.fastq.gz",
            ]

            found = False
            for infile in candidates:
                if infile.exists():
                    shutil.copy2(infile, outdir / infile.name)
                    found = True

            if not found:
                raise FileNotFoundError(
                    f"No FASTQ file was found for {run} in {source}"
                )

        print(f"{barcode}: {row['specimen']} -> {', '.join(runs)}")
PY
```

Check the final directory structure:

```bash
find fastq_pass -maxdepth 2 -type f -name "*.fastq.gz" | sort
```

# ⚠️ Important: ONT basecalling model

The JHMI samples are historical ONT GridION data from the 2022 mpox outbreak.

Do **not** assume that they were basecalled with the model used for the HSPA 2026 sequencing run.

In particular, do not automatically reuse:

```bash
--override_model r1041_e82_400bps_hac_v520
```

for these public reads.

That model describes modern R10.4.1/E8.2 data and is appropriate only when the reads were actually generated with that basecalling model.

The Chen et al. publication reports that the JHMI samples were sequenced on GridION, but it does **not** provide enough information in the paper to justify assigning the HSPA 2026 R10.4.1 model to these historical reads.

Furthermore, FASTQ files reconstructed from SRA may not retain all of the original ONT header metadata that `artic-mpxv-nf` uses for automatic model detection.

Before using these public reads for variant calling, the instructor should therefore verify an appropriate model for the archived data.

This limitation does **not** affect their usefulness for exercises on:

- downloading public data;
- FASTQ organization;
- general read QC;
- read-length distributions;
- teaching the structure of an ARTIC workflow.

For a production-quality consensus analysis, the sequencing chemistry/basecalling model must be verified rather than guessed.
