The dataset used in this training is stored in `~/dataset` and contains mpox reads from ONT amplicon sequencing using Yale scheme.

We can copy the dataset to our workshop directory to stay organized:

```
cp -r ~/dataset/yale_testrun ~/2026-HSPA-Autumn-School/data
```
